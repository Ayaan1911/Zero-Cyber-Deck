Large Ventoy data partition (typically exFAT):
/
|- ISO/                   (download ISOs here yourself and verify their checksums)
|- ZERO-Deck/             (the APPLICATION: code only, installed by Install-ZeroDeck.ps1, matches SHA256SUMS.txt)
|- ZERO-DATA/             (YOUR data: results, notes, evidence, scope, audit log. Never touched by the installer.)
|- ventoy/ventoy.json     (optional, only when configuring persistence manually)
`- persistence/           (optional Kali backend .dat file, created manually on Linux)

The USB is NOT formatted or bootable just by copying this project to it.

PLANNED (not built): the Linux ZERO-DATA belongs on an ext4 partition, not on the exFAT partition above (exFAT has no hard links,
so the Linux side refuses to use it for data). Leave Ventoy's EFI partition (VTOYEFI) unchanged. See SETUP.md "Storage layout".
