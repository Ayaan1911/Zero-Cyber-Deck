Large Ventoy data partition (typically exFAT):
/
|- ISO/                   (download ISOs here yourself and verify their checksums)
|- ZERO-Deck/             (the APPLICATION: code only, installed by Install-ZeroDeck.ps1, matches SHA256SUMS.txt)
|- ZERO-DATA/             (optional Windows data; exFAT is NOT suitable for Linux ZERO-DATA)
|- ventoy/ventoy.json     (optional, only when configuring persistence manually)
`- persistence/           (optional Kali backend .dat file, created manually on Linux)

The USB is NOT formatted or bootable just by copying this project to it.

PLANNED (not built): Linux ZERO-DATA needs a separately mounted supported filesystem; an ext4 partition or image is under Phase 2 review.
The exFAT partition has no hard links, so the Linux side refuses it for data. Leave Ventoy's EFI partition (VTOYEFI) unchanged.
See SETUP.md "Storage layout" and docs/PHYSICAL-USB-BOOT.md for the verified read-only boot path.
